# github_enterprise_team_organizations (Data Source)

Retrieves information about organizations assigned to a GitHub enterprise team.

See the [GitHub REST API documentation](https://docs.github.com/en/rest/enterprise-teams) for required enterprise permissions and supported authentication.

## Example Usage

```terraform

  enterprise_slug = "my-enterprise"
  team_slug       = "ent:platform"
}

output "assigned_orgs" {
  value = data.github_enterprise_team_organizations.example.organization_slugs
}
```
