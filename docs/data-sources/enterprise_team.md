# github_enterprise_team (Data Source)

Gets information about a GitHub enterprise team.

See the [GitHub REST API documentation](https://docs.github.com/en/rest/enterprise-teams) for required enterprise permissions and supported authentication.

Specify exactly one of `slug` or `team_id`.

## Example Usage

```terraform
data "github_enterprise_team" "example" {
  enterprise_slug = "my-enterprise"
  slug            = "ent:platform"
}
```
