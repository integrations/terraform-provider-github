# github_repository_file (Resource)

Resource to manage a file within a GitHub repository.

~> When a repository is archived, Terraform will skip deletion of repository files to avoid API errors, as archived repositories are read-only. The files will be removed from Terraform state without attempting to delete them from GitHub.

## Example Usage

```terraform
# Existing Branch Example

resource "github_repository" "foo" {
  name      = "example"
  auto_init = true
}

resource "github_repository_file" "foo" {
  repository          = github_repository.foo.name
  branch              = "main"
  file                = ".gitignore"
  content             = "**/*.tfstate"
  commit_message      = "Managed by Terraform"
  commit_author       = "Terraform User"
  commit_email        = "terraform@example.com"
  overwrite_on_create = true
}
```

```terraform
# Auto Created Branch Example

resource "github_repository" "bar" {
  name      = "example2"
  auto_init = true
}

resource "github_branch" "bar" {
  branch     = "does/not/exist"
  repository = github_repository.bar.name

}

resource "github_repository_file" "bar" {
  repository          = github_repository.bar.name
  branch              = "does/not/exist"
  file                = ".gitignore"
  content             = "**/*.tfstate"
  commit_message      = "Managed by Terraform"
  commit_author       = "Terraform User"
  commit_email        = "terraform@example.com"
  overwrite_on_create = true
}
```

## Schema

### Required

- `content` (String) Content of the file.
- `file` (String) Path of the file to manage.
- `repository` (String) Name of the repository.

### Optional

- `autocreate_branch` (Boolean, Deprecated) Automatically create the branch if it could not be found. Subsequent reads if the branch is deleted will occur from `autocreate_branch_source_branch`.
- `autocreate_branch_source_branch` (String, Deprecated) The branch name to start from, if `autocreate_branch` is set; this defaults to `main`.
- `autocreate_branch_source_sha` (String, Deprecated) The commit hash to start from, if `autocreate_branch` is set; this defaults to the tip of `autocreate_branch_source_branch`. If provided, `autocreate_branch_source_branch` is ignored.
- `branch` (String) Name of the branch; this defaults to the repository's default branch. The branch must already exist, unless `autocreate_branch` is set.
- `commit_author` (String) Name of the commit author; this defaults to the authenticated user's name and must be set together with `commit_email`. It is only used when the file is written and is not read back from GitHub. GitHub app users may omit author and email information so GitHub can verify commits as the GitHub App, which may be useful when a branch protection rule requires signed commits.
- `commit_email` (String) Email address of the commit author; this defaults to the authenticated user's email address and must be set together with `commit_author`. It is only used when the file is written and is not read back from GitHub. GitHub app users may omit author and email information so GitHub can verify commits as the GitHub App, which may be useful when a branch protection rule requires signed commits.
- `commit_message` (String) Commit message used when creating, updating or deleting the file; this defaults to `Add <file>`, `Update <file>` or `Delete <file>` respectively. It is only used when the file is written and is not read back from GitHub, so changing it on its own will not update the file.
- `overwrite_on_create` (Boolean) Enable overwriting existing files; this defaults to `false`.

### Read-Only

- `commit_sha` (String) SHA of the latest commit that modified the file; this is set when the file is written and refreshed if the file is changed outside of Terraform.
- `id` (String) The ID of this resource.
- `ref` (String) Name of the commit, branch or tag.
- `repository_id` (Number) ID of the repository.
- `sha` (String) Blob SHA of the file.

## Import

Import IDs use the format `repository:file_path:branch`; you may use an empty branch to point at the default branch and any `:` in the file path must be escaped as `??`.

Import is supported using the following syntax:

In Terraform v1.5.0 and later, the [`import` block](https://developer.hashicorp.com/terraform/language/import) can be used with the `id` attribute, for example:

```terraform
import {
  to = github_repository_file.example
  id = "repo-name:path/to/file.txt:main"
}
```

The [`terraform import` command](https://developer.hashicorp.com/terraform/cli/commands/import) can be used, for example:

```shell
terraform import github_repository_file.example repo-name:path/to/file.txt:main
```
