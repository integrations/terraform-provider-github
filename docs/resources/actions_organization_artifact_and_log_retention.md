# github_actions_organization_artifact_and_log_retention (Resource)

Resource to manage how long GitHub Actions artifacts and logs are retained for an organization. The value also caps what each repository in the organization may set.

-> You must have admin access to an organization to use this resource.

~> Destroying this resource resets the organization to GitHub's default retention of 90 days. The REST API has no endpoint for clearing a customised value.

## Example Usage

```terraform
resource "github_actions_organization_artifact_and_log_retention" "example" {
  days = 7
}
```
