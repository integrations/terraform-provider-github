# github_enterprise_team (Resource)

Creates and manages a GitHub enterprise team.

See the [GitHub REST API documentation](https://docs.github.com/en/rest/enterprise-teams) for required enterprise permissions and supported authentication.

## Example Usage

```terraform
data "github_enterprise" "enterprise" {
  slug = "my-enterprise"
}

resource "github_enterprise_team" "example" {
  enterprise_slug             = data.github_enterprise.enterprise.slug
  name                        = "Platform"
  description                 = "Platform Engineering"
  organization_selection_type = "selected"
}
```

## Schema

### Required

- `enterprise_slug` (String) The slug of the enterprise (e.g. from the enterprise URL).
- `name` (String) The name of the enterprise team.

### Optional

- `description` (String) A description of the enterprise team.
- `group_id` (String) The ID of the IdP group to assign team membership with. Removing an existing group ID replaces the team; changing it to another group ID updates the team in place.
- `organization_selection_type` (String) Controls which organizations can see this team: `disabled`, `selected`, or `all`.

### Read-Only

- `id` (String) The ID of this resource.
- `slug` (String) The slug of the enterprise team. GitHub generates the slug from the team name and adds the ent: prefix.
- `team_id` (Number) The numeric ID of the enterprise team.

## Removing an IdP group

Removing `group_id` (or setting it to an empty string) from a linked team requires replacement. The current GitHub SDK cannot encode an explicit JSON null for this field. Terraform shows the replacement in the plan; it deletes the existing team and creates a new team without an IdP mapping. The numeric team ID changes and dependent memberships and organization assignments must be recreated. Changing to a different non-empty group ID remains an in-place update.

Removing `description` clears the remote description in place.
