# github_repository_code_quality (Resource)

Manages the GitHub Code Quality setup for a repository. See the [GitHub Code Quality documentation](https://docs.github.com/en/code-security/how-tos/maintain-quality-code/enable-code-quality) for details.

-> Code Quality must be allowed for the repository's organization. See the [REST API endpoint](https://docs.github.com/en/rest/code-quality/code-quality#update-a-code-quality-setup-configuration) for the required token permissions.

Code Quality runs CodeQL analysis with GitHub Actions. GitHub applies setup changes in the background, so `languages`, `runner_type` and `runner_label` left unset are populated on the next refresh. Destroying this resource disables Code Quality for the repository.

## Example Usage

```terraform
# Analyze Python code on self-hosted runners labeled "code-quality".
# Omit runner_type and runner_label to use GitHub-hosted runners.

resource "github_repository" "example" {
  name       = "my-repo"
  visibility = "private"
}

resource "github_repository_code_quality" "example" {
  repository   = github_repository.example.name
  languages    = ["python"]
  runner_type  = "labeled"
  runner_label = "code-quality"
}
```

## Schema

### Required

- `repository` (String) The name of the repository to configure Code Quality for.

### Optional

- `enabled` (Boolean) Whether Code Quality is enabled for the repository. Defaults to `true`.
- `languages` (Set of String) The languages to analyze. Can be `csharp`, `go`, `java-kotlin`, `javascript-typescript`, `python` or `ruby`. If not set, GitHub selects the languages detected in the repository.
- `runner_label` (String) The runner label used for the analysis when `runner_type` is `labeled`.
- `runner_type` (String) The runner type used for the analysis. Can be `standard` or `labeled`.

### Read-Only

- `id` (String) The ID of this resource.
- `repository_id` (Number) The ID of the repository to configure Code Quality for.
