# github_repository_immutable_releases (Resource)

Manages immutable releases for a GitHub repository.

-> You must have admin access to a repository to use this resource. See the [GitHub documentation](https://docs.github.com/en/code-security/concepts/supply-chain-security/immutable-releases) for details about immutable releases.

## Example Usage

```terraform
resource "github_repository" "example" {
  name       = "example-repo"
  visibility = "public"
}

resource "github_repository_immutable_releases" "example" {
  repository = github_repository.example.name
}
```
