# github_actions_repository_artifact_and_log_retention (Resource)

Resource to manage how long GitHub Actions artifacts and logs are retained for a repository.

-> You must have admin access to a repository to use this resource.

~> Destroying this resource resets the repository to GitHub's default retention of 90 days, capped by `maximum_allowed_days`. The REST API has no endpoint for clearing a customised value.

## Example Usage

```terraform
resource "github_actions_repository_artifact_and_log_retention" "example" {
  repository = "example-repo"
  days       = 7
}
```
